## Marko ID System
- ID is an integer consists of 4 digits
- First 2 digits is year ID where `01` is the first year
- Last 2 digits is an increasing student ID starting from `01`
- Usually student ID is simply student rank in exams before the KAUST Camps
- In case of 2/3 batches in the same year, a gap would be created so the next batch student ID would start from `51` or `71`
- In case of a kicked person, he gets a new ID on his new batch
